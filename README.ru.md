# opensnitch_mcp

MCP-сервер, через который агент для программирования видит межсетевой экран
приложений OpenSnitch.

OpenSnitch умеет запрещать любое исходящее соединение, для которого нет правила.
Программа без правила падает с ошибкой, похожей на обычный сбой сети: таймаут,
отказ в соединении, имя не разрешается. Агент видит такую ошибку и начинает
чинить код, который работает. Сервер даёт агенту способ сначала проверить
межсетевой экран.

## Инструменты

| Инструмент | Что сообщает |
|---|---|
| `opensnitch_status` | Работает ли демон, какое действие по умолчанию, сколько правил загружено |
| `list_rules` | Правила, в имени, операнде или значении которых есть заданная строка |
| `check_process` | Какие правила касаются исполняемого файла и что будет с его соединениями |
| `recent_denies` | Последние заблокированные соединения, можно для одного процесса |
| `add_rule` | Ставит правило, когда пользователь введёт пароль |

Сервер ещё передаёт агенту короткую инструкцию: если сетевой вызов не прошёл,
сначала вызвать `recent_denies` и `check_process`, а потом уже смотреть код.
И никогда не вызывать `add_rule`, не предупредив пользователя.

## Как сервер добирается до правил

Правила лежат в `/etc/opensnitchd/rules`, читать их может только root. Поэтому
есть маленький помощник `opensnitch-rulectl`. Он запускается от root и умеет две
вещи:

- `dump` выводит настройки демона и все правила в JSON. Одна строка в sudoers
  разрешает его без пароля.
- новое правило ставится через `sudo -A`, и на каждое изменение межсетевого
  экрана пользователь видит окно с паролем.

Помощник собран в один файл и ничего не импортирует из этого каталога: сюда
может писать пользователь, а помощник работает от root. Каждое поле он сверяет
со своим белым списком действий, сроков, операндов и типов операторов.

Заблокированные соединения сервер берёт из базы статистики интерфейса OpenSnitch.
По умолчанию интерфейс держит статистику в памяти. Если файла базы нет,
`recent_denies` подскажет, как включить запись на диск.

## Установка

Нужны Linux с OpenSnitch, Python 3.10 или новее, пакет `fastmcp` и переменная
`SUDO_ASKPASS` с графическим окном ввода пароля.

```sh
pip install fastmcp
sudo -A bash install.sh
```

`install.sh` кладёт помощник в `/usr/local/bin`, добавляет строку в sudoers и
пишет несколько правил для программ, у которых путь меняется при каждом запуске
или обновлении (AppImage, Claude Code, GE-Proton). Прочитайте скрипт и уберите
лишнее.

Подключите сервер к своему MCP-клиенту, например к Claude Code:

```sh
claude mcp add opensnitch -- python3 /path/to/opensnitch_mcp/server.py
```

Путь к базе статистики можно задать переменной `OPENSNITCH_STATS_DB`.
